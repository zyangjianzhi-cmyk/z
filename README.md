# Lumina · 即梦视频工作室

一个轻量、简洁的本地视频创作软件。浅色界面、自绘 SVG 图标、响应式布局，无需安装前端依赖。

仅调用 **`seedance2.0fast_vip`**，支持文字生成视频、6 种画幅、4–15 秒、720p。包含即梦账户连接、积分查询、生成队列、自动状态更新、视频预览和本地作品记录。每次生成前会确认积分消耗；不内置其他模型或自动切换模型。

## 启动

需要 Node.js 20+、已安装的 Dreamina CLI，以及可用的即梦账户。先在终端确认：

```bash
node --version
dreamina --version
```

在此项目目录运行：

```bash
npm start
```

在**运行软件的同一台电脑**浏览器打开终端显示的本机地址（默认端口 3000）。服务器默认只监听本机。开发时可用 `npm run dev`。

无需 `npm install`，项目只使用 Node.js 内置模块。若端口被占用，可设置 `PORT`；CLI 不在 PATH 时，设置 `DREAMINA_BIN` 为其完整路径。

也可以在 Windows 双击 `start.bat`，在 macOS 双击 `start.command`（首次可能需要 `chmod +x start.command`）。这些启动脚本仍需要提前安装 Node.js 和 Dreamina CLI。

环境变量设置方式取决于系统，例如 macOS/Linux：

```bash
PORT=3001 DREAMINA_BIN="$HOME/.local/bin/dreamina" npm start
```

云环境中的本机地址不能直接在你自己的电脑访问。要在自己的电脑使用，请下载项目代码，在该电脑安装 Node.js 和 Dreamina CLI 后启动；也可以通过你已有的安全端口转发访问，应用不附带公网部署。

## 使用

1. 启动后自动复用当前机器的 Dreamina 登录状态并查询积分。
2. 未登录时，点击左下角账户，再点击「在浏览器中授权」。会打开官方授权页；若即梦登录在另一个浏览器，复制弹窗内的链接到那个浏览器。应用自动查询授权结果并确认成功。
3. 描述画面，选择画幅和时长，点击「生成视频」并确认积分消耗。任务异步执行，页面自动更新。
4. 成功后可以播放视频，点击「打开 / 保存视频」，在视频页面使用浏览器保存功能。
5. 「我的作品」可以按状态筛选，选择记录预览、复用描述或移除本地记录。

账户状态由 Dreamina CLI 管理；本应用不读取或复制登录凭证。CLI 需要能写入其用户目录（通常是 `~/.dreamina_cli`）。云沙箱内需使用平台提供的权限机制允许运行 CLI 写入该目录以及访问即梦服务。

作品记录存于 `.data/tasks.json`，不提交 Git。记录只包含描述、参数、任务状态及结果 URL。即梦结果链接可能过期；请及时保存视频，过期后可在即梦网页查看作品。移除记录不删除即梦作品，也不会退还积分。

## 异常处理

- `AigcComplianceConfirmationRequired`：在即梦网页使用此模型完成首次确认，再回来生成。
- 网络或 CLI 错误：页面显示具体报错。已返回任务编号的生成会继续查询，不重复提交。
- 提交过程中服务中断或超时：标记为「需要核实」，请先查看即梦网页或 CLI 任务记录，确认是否已提交和扣费。应用不会自动重新提交。
- 生成进行中关闭网页：后端继续运行时任务会继续更新。重启后会恢复有编号任务的查询。本地尚未提交的队列会继续提交；提交状态不明的任务不会重试。
- 不提供取消已提交的云端任务；生成中的记录不支持移除。最多 3 个未完成任务，提交串行执行。
- 同一份作品数据只允许运行一个工作室实例，避免重复提交。正常退出会释放运行锁；进程异常退出后会自动识别失效锁。

## 验证

```bash
npm test
```

测试用替身 CLI 验证固定模型、参数校验、异步状态、失败处理、重启恢复、授权流程和本地访问保护，不消耗积分。真实生成需要即梦账户有对应模型的权益、积分及网络访问；仅通过测试和账户查询不代表真实付费视频生成已验证。

## 文件

- `server.mjs`：本地 HTTP 服务、CLI 桥接与持久化队列。
- `public/`：无构建步骤的界面与自绘图标。
- `test/`：Node.js 内置测试框架。

CLI 使用独立参数调用，未启用 shell 执行；前后端均限制固定模型，后端固定 720p。应用仅供本机个人使用，不包含多用户认证或公网服务能力。
